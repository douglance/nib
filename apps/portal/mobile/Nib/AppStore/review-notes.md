# App Review notes

Nib is a free stand-alone companion app for the paid Nib web-based developer tool under App Review Guideline 3.1.3(f). The native app contains no purchasing, pricing, subscription-management UI, or call to action for purchasing outside the app.

## Review access

Nib uses passwordless email sign-in. App Review can enter any email address it can access. Opening the one-time link creates the account and signs the app in; no paid subscription is required to sign in. A brand-new account has empty private cloud history by design.

## Features to review

- Inbox and request detail: requests sent to the signed-in account appear here.
- Visual review: open a visual request and add an annotation.
- Library: browse immutable cloud history. Editing creates a new `.nib`; it never changes the source record.
- Account deletion: Settings > Account > Delete Account.
- Mac capture: choose display, window, or region capture to create the first cloud file. macOS requests Screen Recording permission on first use.
- Notifications: push delivery requires a physical device and notification permission.
